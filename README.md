# LogicLayerWebsite

## Import from local location

If you need to import/use this project from your local machine, use your local folder path, for example:

`%USERPROFILE%\OneDrive\Documents\LogicLayerWebsite`

Examples:

- VS Code: **File → Open Folder** and select the path above.
- Node/npm local dependency:
  - `npm install "%USERPROFILE%\\OneDrive\\Documents\\LogicLayerWebsite"`
  - or in `package.json`: `"logic-layer-website": "file:../LogicLayerWebsite"` (or your absolute local path)
